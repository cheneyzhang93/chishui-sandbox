一分钟读懂 7 条规则 —— 目标 / 一个回合 / 移动 / 攻击 / 侦察 / 结算 / 疲劳
  1. 目标：红军 8 个回合内送 2 个单位进最左一列（西岸脱离区）；送不到，蓝军胜。
    全队是 3 个 —— 任务线只是「主力过河」（历史上此役的目标就是主力脱险）。剩下 1 个留在东岸是本仗的代价， 结算里会点名是谁；把 3 个全送过去则照实报「一个不少」（8 个回合内极难做到）。
  2. 一个回合：给每个红军单位下令 → 点「推进一回合」→ 双方同时结算 → 右栏播报。
    结算会一条一条演出来：谁先动、谁撞上谁、哪一格打起来（棋盘闪光 + CRT 那一格亮）、谁掉了兵， 演到哪条就点亮右栏哪条播报；不想等就点棋盘（或那个「点此跳过」的按钮）直接看结果。
  3. 移动：每单位 3 点机动，走一格按地形扣 1—3 点（坡越陡越贵；渡口固定 3、隘口 ≥2、城镇 1）；赤水河不可通行，只有两处渡口能过。
    下令时画的金线就是它这回合的行军路线（实线 = 本回合走到，虚线 = 预告的后续）；引擎按这条线走， 只有路被占住才改道或停下，且右栏播报会写明原因（到不了的目标格会当场拒收命令）。
  4. 攻击：只能打相邻且已发现的敌军；下攻击命令的这回合不移动，等于用一步换一次交战。
  5. 侦察：基础视野 3 格（曼哈顿距离），站在非平地形（隘口 / 城镇 / 渡口 / 山地）再 +1，当回合下「侦察」命令再 +2；看不见的敌人不能打。
    看不见就不知道：蓝军一旦脱离你的视野，地图上只留一个蓝色虚线框「?」——几回合前的位置，外加一个金色箭头指它最后朝哪走（只给方向，不给速度）。它的行军不进播报、不留实况线，直到你再看见它、或它打到你眼前。
  6. 结算：1 颗 1d6 × 攻守有效兵力比 → 查中栏战斗结算表（CRT，点标题展开）得 A2/A1/E/D1/D2/X。
  7. 疲劳：连续机动累积疲劳、削弱有效兵力；原地不动会恢复。
本件验证什么 / 不做什么

验证的是循环：读情报 → 下命令 → 双方同时结算 → 出事件 → 播报。跑通了，才谈得上「游戏底座」。

不做什么：棋盘本身仍不接真实地图、兵力量化为抽象当量、番号为占位符（红1/蓝1）；这不是史实推演，也不构成战史结论，不得对外发布。经纬度只在 core/grid-geo.js 里做一次**示意**映射，供地图页叠格网用 —— 格网是作战分区，不是真实境界。

已知简化（都是下一步要还的债）：

  • 机动按「红先蓝后」顺序结算，不是真正的同步解算（真 WEGO 要冻结同一快照 + 冲突仲裁）—— 两处渡口东岸都只有一格宽，红方先动就先占。
  • 蓝方是「守口 + 预备队」的简化决策：两个单位按最近原则分派到两处渡口的东岸口子（上回合守哪、这回合续任，免得来回换位），第三个人当预备队，按军级情报往红军更逼近的那处渡口补 —— 没有上帝视角，只认自己看见的。红方 AI 是「主队 + 诱饵」：一个单位明着朝另一处渡口去（只摆样子、不开火）把预备队钉在错的方向，主队再打防守弱的那一处。都不是完整的指挥模型。
  • 侦察是一个曼哈顿半径，「最后已知位置」不做概率衰减；动向只给方向，不给速度与兵力。

已接上：地图页 ?game=种子 把格网叠到真实地形上并按本局回放（core/grid-geo.js 落点 + core/replay.js 快照与日志）；state.log 每条事件都带结构化字段，按《行军日志字段表》产出 simLog（见该表 §1.1）。

下一步：把「红先蓝后」换成真正的同步解算；情报加概率衰减与上报延迟；把 AI 从「规则表」换成按任务分解的指挥官模型。

这是一盘「命令 → 结算 → 播报」的格子棋

你是红军指挥官。目标：8 个回合内把 2 个单位送过赤水河——地图最左一列是西岸脱离区，只有两处渡口能过河；送不到就判负。
全队 3 个，任务线是「主力过河」：送过去 2 个就算达成，剩下 1 个（在东岸牵制敌人的那一路）留在东岸是本仗的代价 —— 结算会点名是谁。

  1. 点一个红军单位（地图上的红棋子，或左栏列表）。没下令的单位会被金色虚线圈住。
  2. 点「移动」再点目标格；不想动就点「固守 / 侦察 / 攻击 / 脱离」。
  3. 点「推进一回合」——双方同时结算，右栏播报会一条一条亮起来演给你看（点棋盘可跳过）。

不想先动脑也行：什么都不下令直接「推进一回合」，看蓝军怎么堵你；或者勾「红方交 AI」，先看一局完整的循环。
